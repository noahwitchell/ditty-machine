# Ditty Machine

A phone-first piano-roll step sequencer for short musical ditties. One `index.html`, no build step; every sound is synthesised with the Web Audio API.

- Stack instruments: keys, mellotron, tuned percussion, synths, retro game tones, two drum kits
- Draw notes on a 12-note grid, drag for long notes, tap a note to move it up/down an octave
- Grid from 1/4 to 1/32, 1–8 bars, any BPM
- Tap/drag the ruler to move or scrub the playhead; loop a bar or section from the strip above it

Live: https://noahwitchell.github.io/ditty-machine/

Add it to your phone's home screen (Safari → Share → Add to Home Screen) for a full-screen app with its own icon.
